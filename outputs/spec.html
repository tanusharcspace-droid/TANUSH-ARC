1. Course Objectives
  1. To introduce foundational concepts of abstract data types and algorithmic complexity.
  2. To analyze linear and non-linear data structures including trees, balanced search structures, and graphs.
  3. To design and evaluate efficient sorting, searching, and hashing strategies for computational tasks.
2. Course Learning Outcomes (CLOs) & Bloom Taxonomy
CLO Code Outcome Statement Bloom Level
CO1 Analyze the asymptotic time and space complexity of iterative and recursive algorithms using Big-O, Big-Omega, and Big-Theta notations. L4
CO2 Construct and implement singly linked, doubly linked, circular linked lists, stacks, and circular queues for dynamic memory management. L3
CO3 Evaluate binary trees, binary search trees (BST), and AVL tree self-balancing rotations during dynamic data updates. L5
CO4 Design graph models and compute shortest paths, topological sort orders, and minimum spanning trees using BFS, DFS, Dijkstra, and Kruskal algorithms. L4
CO5 Implement collision resolution strategies in hash tables including separate chaining and open addressing with linear and quadratic probing. L3
