CS304: Distributed Systems & Cloud Computing

Credits: 4 • L-T-P: 3-0-2 • Total Contact Hours: 75
Course Category Professional Core (PC)
Prerequisites CS201 Data Structures, CS204 OS
Assessment Strategy CIE: 50% | SEE: 50%

1. Course Objectives

Editable by Author
  • Examine fundamental architectural models, communication primitives, and state synchronization across distributed nodes.
  • Analyze consensus protocols (Paxos, Raft), Byzantine agreement, and distributed commit semantics under asynchronous fault domains.
  • Construct scalable, fault-tolerant cloud microservices using distributed storage frameworks and container orchestration.

2. Syllabus Units & Content Delivery

UNIT I: FOUNDATIONS & LOGICAL TIME 9 Lecture Hours • Bloom L2-L3

Characterization of distributed systems; System models (architectural, interaction, failure models). Remote Procedure Calls (gRPC, protocol buffers). Logical Clocks: Lamport timestamps, Vector clocks, Matrix clocks. Global state recording: Chandy-Lamport snapshot algorithm. Distributed mutual exclusion: Ricart-Agrawala, Maekawa quorum.

UNIT II: CONSENSUS & REPLICATION 9 Lecture Hours • Bloom L3-L4

Fault tolerance fundamentals: Crash-stop vs. Byzantine failures. Consensus in synchronous vs. asynchronous systems; FLP impossibility result. Paxos protocol (Classic & Multi-Paxos), Raft consensus algorithm (Leader election, Log replication, Safety). Primary-backup replication, Viewstamped Replication, State Machine Replication (SMR).

UNIT III: DISTRIBUTED STORAGE & TRANSACTIONAL SEMANTICS 1 REVIEW NOTE
9 Lecture Hours • Bloom L4-L5

Distributed transactions: Atomicity, Consistency, Isolation, Durability (ACID). Two-Phase Commit (2PC) and Three-Phase Commit (3PC). CAP Theorem and PACELC trade-offs. Distributed hash tables (Chord, Dynamo DHT), consistent hashing with virtual nodes. Google Spanner: TrueTime API and external consistency.

UNIT IV & V: CLOUD SYSTEMS & INTEGRATED EXPERIMENTAL LAB 27 Lecture Hours + 30 Lab Hours

Cloud infrastructure virtualization: hypervisors, containers (OIDC, Kubernetes architecture). MapReduce and Spark distributed compute primitives. Serverless compute runtimes and event-driven orchestration.

Approved Integrated Laboratory Schedule:
  1. Implement gRPC microservice with bi-directional streaming and payload serialization.
  2. Simulate Lamport Clock event ordering across 4 asynchronous Docker containers.
  3. Implement Raft consensus leader election and heartbeats with simulated packet drops.
  4. Build a consistent-hash Key-Value store with node joining/leaving repartitioning.
  5. Deploy auto-scaling stateless REST API on Kubernetes cluster with ingress routing.
