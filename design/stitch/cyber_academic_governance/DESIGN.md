## Brand & Style

This design system synthesizes high-order cryptographic governance, institutional rigor, and underground cybernetic telemetry. Built for advanced protocol architects, sovereign councils, and security researchers, the aesthetic balances high-stakes institutional authority with hyper-technical execution.

The aesthetic fuses **Technical Brutalism** with **Cyber-Academic Formalism**:
- **Atmosphere:** Pitch-black command chambers, luminescent protocol telemetry, and surgical precision.
- **Visual Tension:** Extreme contrast between void-black substrates, stark academic editorial typography, and electric purple spectral emissions.
- **Tone:** Authoritative, impenetrable, hyper-functional, and mathematically rigorous.

## Colors

The palette establishes an aggressive luminance hierarchy engineered strictly for OLED-level extreme dark mode.

### Palette Architecture
- **Pitch Substrates:**
  - `void-000` (`#000000`): Canvas base, zero-point depth.
  - `void-100` (`#050508`): Primary surface substrate for layout architecture.
  - `void-200` (`#0a0612`): Elevated cards, panels, and modal planes carrying a trace violet undertone.
  - `void-300` (`#140c24`): Structural containers and interactive hover fills.
- **Primary & Accent Luminescence (Electric Violet & Royal Purple):**
  - `primary-neon` (`#c084fc`): High-attention interactive triggers and active glyphs.
  - `primary-base` (`#a855f7`): Core brand, key CTAs, and active navigation indicators.
  - `primary-deep` (`#9333ea`): Focused borders and structured glow falloffs.
  - `primary-spectral` (`#7c3aed`): Atmospheric glow sources and backdrop gradients.
- **Terminal & Telemetry (Hacker Monospace Green):**
  - `terminal-bright` (`#00ff66`): Critical status pulses, verified quorum badges, and real-time execution states.
  - `terminal-base` (`#22c55e`): Code blocks, cryptographic hashes, voting tally differentials, and inline syntax.
  - `terminal-muted` (`#10b981`): Secondary metrics, network latency, and non-blocking logs.
- **High-Contrast Typography & Rules:**
  - `text-stark` (`#ffffff`): Canonical headlines, active state labels, and mathematical symbols.
  - `text-crisp` (`#f3f4f6`): Primary prose, parameter descriptors, and tabular figures.
  - `text-subtle` (`#94a3b8`): Secondary metadata, timestamps, and inactive iconography.
  - `text-faint` (`#475569`): Column grid rules, disabled states, and structural bracket syntax.

## Typography

The typographic hierarchy establishes clear domain separation:
1. **Space Grotesk (Editorial & Governance Architecture):** Structural, geometric, and uncompromising. Used exclusively for institutional sectioning, proposal titles, and system parameters.
2. **Geist (Neutral Systematic Prose):** Delivers clean readability for policy briefs, dispute texts, and governance discourse.
3. **JetBrains Mono (Protocol Telemetry & Computation):** Powers contract addresses, voting quorums, state tags, timestamps, and all numerical governance payloads. Must always be used for uppercase data labels with expanded letter-spacing.

## Layout & Spacing

The layout is governed by a technical 12-column rigid grid system bound by hairline structural borders.

### Grid & Breakpoints
- **Mobile (<768px):** 4 columns, `margin-sm: 1rem`, `gutter-sm: 1rem`. High-density, single-column reflow for all analytical cards. Side navigation collapses into an anchored terminal status bar.
- **Tablet (768px - 1024px):** 8 columns, `margin: 2rem`, `gutter: 1.5rem`. Split viewport allocating 3 columns to proposal metadata and 5 columns to parameter telemetry.
- **Desktop (>1024px):** 12 columns, max-width `1600px`, `margin-lg: 4rem`, `gutter-lg: 2rem`. Multicolumn operations desk: Fixed 2-column systemic sidebar, 7-column execution core, and 3-column verification inspector.

### Spacing Philosophy
Internal density operates on a hard 4px base rhythm. Layout spacing between disparate architectural zones must feel vast and monumental, contrasting with the razor-thin, condensed packing of monospace data tables.

## Elevation & Depth

This system rejects physical drop shadows. Depth is executed through **spectral luminescence**, **tonal stratification**, and **razor-sharp chromatic boundary lines**.

### Architectural Elevation Planes
- **Base Level (Canvas):** `#000000` with subtle synthetic background gridlines (`rgba(168, 85, 247, 0.04)` spaced at 32px intervals).
- **Surface Level 1 (Panels & Desks):** `#050508` framed by a 1px border of `rgba(168, 85, 247, 0.22)`.
- **Surface Level 2 (Inspector Overlays & Active Nodes):** `#0a0612` framed by a 1px border of `rgba(168, 85, 247, 0.45)`.
- **Focus / Elevated Modals:** `#0a0612` with a 1px outline of `#a855f7` backed by an ambient aura: `box-shadow: 0 0 24px rgba(124, 58, 237, 0.28), 0 0 60px rgba(168, 85, 247, 0.12)`.

### Chromatic Edge Lighting
Every edge uses a 1px solid stroke. Inactive elements use muted, cold borders (`rgba(255, 255, 255, 0.1)`). Active or critical governance nodes project a violet optical glow (`box-shadow: inset 0 0 12px rgba(168, 85, 247, 0.15)`). Monospace verification states replace the violet perimeter with pure terminal green radiance (`box-shadow: 0 0 16px rgba(0, 255, 102, 0.35)`).

## Shapes

The design system enforces **zero roundedness (`0` - Sharp)** across the entire component library. 

- All containers, action triggers, text inputs, dialogs, and status chips possess surgically sheared `0px` corners.
- Aesthetic reinforcement: Diagonal chamfers (45-degree clip-paths, 8px × 8px) may be deployed strictly on primary action buttons and verification stamp badges to evoke classified security hardware.
- Dividers are uncompromising 1px hairline rules without feathering.

## Components

### Buttons
- **Primary Execution (CTA):** `#000000` background, 1px solid `#a855f7`, text `#ffffff` in `Space Grotesk` (uppercase, bold). Hover triggers a transition to background `#a855f7`, text `#000000`, accompanied by an outer violet luminescence (`0 0 20px rgba(168, 85, 247, 0.6)`).
- **Terminal Action (Consensus / Sign):** `#050508` base, 1px solid `#00ff66`, text `#00ff66` in `JetBrains Mono`. Hover triggers background `#00ff66`, text `#000000`, with a neon green aura.
- **Ghost Utility:** `#transparent` base, 1px solid `rgba(255, 255, 255, 0.15)`, text `#f3f4f6`. Hover promotes border to `rgba(168, 85, 247, 0.5)`.

### Chips & Protocol Badges
- Strict `0px` radius. Monospace caps (`label-caps`).
- **Quorum Passed / Active:** 1px border `#00ff66`, text `#00ff66`, background `rgba(0, 255, 102, 0.06)`. Accompanied by a leading flashing green status glyph (`●`).
- **Emergency / Contested:** 1px border `#f43f5e`, text `#f43f5e`, background `rgba(244, 63, 94, 0.08)`.
- **System Parameter / Epoch Tag:** 1px border `#7c3aed`, text `#c084fc`, background `rgba(124, 58, 237, 0.12)`.

### Lists & Data Grids
- Tabular records rendered with `JetBrains Mono` for all value cells.
- Row items demarcated by horizontal hairline borders (`1px solid rgba(255, 255, 255, 0.06)`).
- Row hover triggers an immediate background tint of `rgba(168, 85, 247, 0.06)` and illuminates the leftmost indicator bar with a 2px `#a855f7` vertical line.

### Input Fields & Terminal Consoles
- Background `#050508`, 1px border `rgba(255, 255, 255, 0.18)`, text `#ffffff` in `JetBrains Mono`.
- Active focus state: Border snaps to `#a855f7` with `box-shadow: 0 0 12px rgba(168, 85, 247, 0.3)`.
- Input fields display an automated leading prompt character (`> `) in `#a855f7`.

### Checkboxes & Binary Selectors
- Sharp square boxes (`16px x 16px`), 1px solid `rgba(255, 255, 255, 0.25)`, background `#000000`.
- Checked state: Border `#a855f7`, background `#a855f7`, containing an uncompromising square pixel glyph in `#000000`.

### Cards & Governance Dossiers
- Deep background (`#0a0612`), 1px perimeter border (`rgba(168, 85, 247, 0.2)`).
- Top header band separated by a 1px border line displaying the dossier title in `Space Grotesk` alongside a right-aligned cryptographic timestamp in green `JetBrains Mono`.
- Hovering triggers a razor-edge highlight enhancement (`border-color: #a855f7`).

### Cryptographic Telemetry Display (Specialized Component)
- High-density monospace block displaying smart contract code, raw hex streams, and transaction logs.
- Background `#000000`, 1px border `rgba(0, 255, 102, 0.2)`.
- Line numbering rendered in `text-faint`, syntax highlights rendered in alternating terminal green (`#22c55e`), electric lilac (`#c084fc`), and stark white (`#ffffff`).
